# SwiftUI Glow Animations

A Swift package, `GlowAnimations`, that recreates nine glowing motion-design scenes in SwiftUI, each drawn as a pure function of time. A demo iOS app plays every scene, and a record/compare harness checks our frames against the reference video.

Work in progress — scenes being implemented.

Recreates the motion design of a reel by Louis Raille (louisraille.fr) as a SwiftUI study; not affiliated with or endorsed by the author.
